# How to use Ivy

The maintained first-run, setup, validation, recovery, and private-content instructions live in the [README](../README.md). This page keeps the daily content loop concise.

1. Capture one unit of thinking with `templates/snapshot.md`; summarize rather than paste a transcript.
2. Store it under `snapshots/` with the filename and metadata defined by the [snapshot schema](../protocols/snapshot-schema.md).
3. Extract reusable outputs into artifacts and recurring ideas into concepts.
4. Link objects by ID instead of copying their contents.
5. Run `python3 scripts/validate.py`, rebuild the registry, and review the diff.
6. Search and reuse existing objects before starting the same reasoning again.

The golden rule: when knowledge becomes reusable, give it one canonical home and link to it.
